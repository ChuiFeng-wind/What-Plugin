# 欢迎使用 WhatPlugin

WhatPlugin 是给音乐人和混音师用的音频插件管理软件。插件越装越多以后，常见的麻烦是：记不清装了什么、哪个账号买的、哪些一直没用、换电脑要重装哪些、工程打开缺了什么。WhatPlugin 把这些都整理在一个地方。

它能做的事：

- **扫描插件**：自动找出电脑上的 VST3 / VST2 插件，认出厂家和功能分类。扫描时不弹授权窗口，一个插件出问题也不会让整个扫描崩溃。
- **整理插件库**：按功能（EQ、压缩、混响…）或适合的音色（人声、鼓、吉他…）分类，打分、写使用感受、打标签。
- **分析工程**：只读读取 DAW 工程，看每个工程用了哪些插件、缺了哪些、哪些插件一直闲着。
- **混音笔记**：把效果链记下来，每一步写首选插件、备选插件和应用思路，也可以直接从工程导入轨道。
- **账号与心愿单**：记下每个插件用哪个账号买的（密码加密保存），想买的插件放进心愿单。
- **健康检查**：找出重复安装、只有 32 位、读取失败、文件丢失等问题。
- **DAW 内查询**：附带一个 VST3 小插件 WhatPluginLookup，在 DAW 里就能查到你写的备注和推荐。

> 所有数据只保存在你自己的电脑上，软件不上传任何内容。工程文件只读不改，也不读取、不修改 iLok / PACE 的授权数据。

本手册对应 WhatPlugin 1.3.0。截图中的插件、工程和账号都是演示数据。

# 系统要求与安装

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11，64 位 |
| 磁盘空间 | 约 140 MB（不含数据库） |
| 插件格式 | 扫描 VST3、VST2；同时记录 CLAP 和 AAX 的文件信息 |
| 支持读取的工程 | Cubase / Nuendo、Studio One、REAPER、Ableton Live |
| DAW 内查询插件 | 支持 VST3 的 64 位宿主 |

## 选择安装包

在发布页面可以看到三个文件：

| 文件 | 说明 |
| --- | --- |
| WhatPlugin-Setup-版本号-with-Achievements.exe | 完整安装包，带成就页面（推荐） |
| WhatPlugin-Setup-版本号.exe | 完整安装包，不带成就 |
| WhatPlugin-Achievements-版本号.exe | 单独的成就包，给已经装了不带成就版本的人补装，版本号要和主程序一致 |

## 安装步骤

1. 安装前先关闭 Cubase、Studio One 等宿主软件。
2. 运行安装包。安装包没有数字签名，Windows 可能提示“Windows 已保护你的电脑”，点“更多信息”→“仍要运行”。
3. 选择安装位置，默认是 `C:\Program Files\WhatPlugin`。
4. 在“选择附加内容”里，建议保留“安装 DAW 内查询窗口（VST3 插件 WhatPluginLookup）”。查询插件会装到 `C:\Program Files\Common Files\VST3`。
5. 安装完成后打开 WhatPlugin。

> 如果安装时宿主软件还开着，并且加载过查询插件，安装程序会提示：点“重试”（关闭宿主后继续）、“忽略”（这次不更新查询插件，其余照常安装）或“中止”。

## 从旧版本升级

直接运行新版本的安装包覆盖安装即可，插件资料、笔记、账号和心愿单都会保留。

从 1.2.6 及以前的版本升级时，安装程序还会自动完成改名：

- 安装目录从 `What Plugin` 搬到不带空格的 `WhatPlugin`，旧目录删除。
- 单独装的成就包一起搬过去，不用重装。
- 旧的 `What Plugin Lookup.vst3` 和旧快捷方式自动清理，换成 `WhatPluginLookup.vst3`。

老工程里用过查询插件的照样能打开：宿主按插件 ID 识别，不看文件名。

## 卸载

在 Windows“设置 → 应用”里卸载 WhatPlugin。卸载只删除程序文件和查询插件，你的数据库会保留，以后重新安装还在。

## 数据保存在哪里

| 内容 | 位置 |
| --- | --- |
| 数据库（插件资料、笔记、账号、心愿单等） | `%LOCALAPPDATA%\WhatPlugin\plugins.db` |
| 程序文件 | `C:\Program Files\WhatPlugin`（或你选择的位置） |
| 查询插件 | `C:\Program Files\Common Files\VST3\WhatPluginLookup.vst3` |

换电脑时，请用软件里的“导出备份”迁移数据，不要只复制数据库文件（加密的密码换了 Windows 账号就解不开）。

# 快速上手

## 第一次打开

第一次打开时会出现欢迎页，有三个选项：

- **开始扫描并参观**：扫描插件（在后台进行，进度显示在窗口底部），同时开始界面导览。推荐新用户选这个。
- **只看导览**：先不扫描，只看每个页面的介绍。
- **跳过**：直接进入软件。

![欢迎页](welcome.png)

## 界面导览

导览会按左侧导航逐个介绍每个页面，当前页面会被高亮圈出。

- 下一步：点“下一步”，或按 Enter、→、PageDown
- 上一步：点“上一步”，或按 ←、PageUp
- 退出：点“跳过”，或按 Esc

以后想再看一遍，在“设置 → 新手指引”里点“重新查看”。

![界面导览](tour.png)

## 五分钟上手

1. **扫描插件**：在“设置”里点“扫描新增”。VST3 使用系统标准位置，VST2 要先“添加并扫描”你的 VST2 文件夹。
2. **整理插件库**：到“插件库”给常用的插件打分、写使用感受。
3. **添加工程文件夹**：到“工程”点“添加文件夹”，选择你存放工程的文件夹，再点“扫描工程”。
4. **看闲置报告**：扫描过工程以后，“闲置报告”会列出很久没用的插件。
5. **记一条混音笔记**：到“混音笔记”新建一条笔记，或者“从工程导入轨道”。

- 浅色：纸白琥珀、雾白蓝

# 扫描插件

## 扫描是怎样进行的

WhatPlugin 用一个单独的扫描进程读取插件：

- 只读取插件的清单信息，不创建插件实例，所以**不会弹出授权窗口**，也不会打开音频设备。
- 每个插件单独处理。某个插件崩溃或卡死，只影响这一个文件，扫描继续进行。
- 不打开插件界面，不改动插件文件。

## 扫描 VST3

VST3 使用系统标准位置（`C:\Program Files\Common Files\VST3`），不需要设置。在“设置”里：

- **扫描新增**：只扫描新增或有变化的文件，速度快，平时用这个。
- **完整重扫**：重新扫描全部文件，也会重试之前读取失败的插件。
- **停止扫描**：随时中止。

## 扫描 VST2

VST2 没有统一的安装位置，需要你告诉软件：在“设置”的 VST2 区域选择文件夹，点“添加并扫描”。子文件夹会一起扫描。

VST2 文件本身分不出是效果器还是音源。WhatPlugin 会读取各 DAW 自己的插件记录来区分，支持：

- Cubase / Nuendo
- REAPER
- FL Studio
- Cakewalk
- Studio One

> 新装的 VST2 插件，请先在 DAW 里扫描一次，再回到 WhatPlugin 扫描，这样才能正确区分效果器和音源。这些记录里都没有的插件，会用厂家目录来判断。

不再需要的文件夹可以点旁边的移除按钮，只是不再读取，插件文件不受影响。

## 厂家识别

软件自带厂家目录，收录约 154 个厂家、5000 多个产品名，用来自动识别插件属于哪个厂家、属于什么功能分类。识别错了可以在插件详情里手动修改，也可以点“恢复自动分类、音色和厂家”撤销手动修改。

# 插件库

插件库列出所有扫描到的效果器（不含音源）。

![插件库](plugins.png)

## 分类栏

左边是分类栏，上方切换两种分类方式：

- **功能分类**：EQ、动态、压缩、限制器、去齿音、混响、延迟、失真/饱和……
- **音色分类**：人声、贝斯、鼓、吉他、键盘……

选一个分类，就能把同类插件放在一起比较。插件详情里的“看同类”会直接跳到它所属的分类。

## 搜索与筛选

- 搜索框可以搜插件名、厂家、分类、标签或备注。
- 下拉框按厂家、格式、评分筛选。
- “清除筛选”恢复显示全部。

## 插件详情

选中一个插件，右边显示它的详情：

- **评分**：一到五星。再点一次当前星级可以清除。
- **使用感受**：写下这个插件的特点、适合用在哪里。
- **我的标签**：自定义标签，比如“人声必备”。
- **混音属性**：延迟（无 / 低 / 高）、CPU 占用（轻 / 中 / 重）、过采样、线性相位、侧链。这些靠手动填写，软件不运行插件，所以不测量。推荐时只排除填了且不符合的插件。
- **功能分类与音色分类**：点“编辑分类”修改。
- **厂家、类型、获取方式**：获取方式可以标为免费、已购或其他（比如捆绑赠送），默认未标记。标成“已购”的插件会自动加进“已购账号”，在那里填账号和授权信息。
- **已安装版本**：列出这款插件的各个文件（不同格式、不同位置）。可以勾选不需要的版本，点“删除选中的版本…”。文件会移到回收站，可以在详情里恢复；至少要留下一个可用的版本。

## 推荐

插件库顶部的推荐框可以用一句话描述需要的功能，例如：

- 人声去齿音
- Waves 的压缩
- 低延迟的人声压缩
- 延迟 不要磁带

点“推荐”，软件会从你已有的插件里找出合适的，并给出推荐理由。点“退出推荐”回到普通列表。

## 移入垃圾桶

不想要的插件可以移入垃圾桶，并填写移入原因（选填）。移入垃圾桶只是在本软件中隐藏，文件不动，DAW 里仍然可以使用。

# 工程分析

工程页读取你的 DAW 工程文件，列出每个工程用到的插件，并汇总缺失的插件。

![工程](projects.png)

## 添加工程文件夹

1. 点“添加文件夹”，选择存放工程的文件夹。子文件夹也会一起读取。
2. 点“扫描工程”。之后再点只读取新增或有变化的工程。

支持 Cubase、Nuendo、Studio One、REAPER、Ableton Live。

> 工程分析只读取工程文件，不修改工程，也不加载插件。

## 查看结果

- **全部工程**：列出所有工程，包括宿主、最近修改时间、效果器数量、缺失数量。
- **有缺失**：只显示缺插件的工程。
- **缺失汇总**：把所有工程缺的插件汇总在一起，看每个缺失插件在几个工程里用到、最近用在哪个工程。

选中一个工程，下方显示它用到的效果器；“在文件夹中显示”可以在资源管理器里定位这个工程文件。

## 不算缺失

有些插件是宿主自带的，或者你确定不再需要。选中后标为“不算缺失”，以后就不再提示。标错了可以点“恢复忽略的名称”。

在垃圾桶里卸载过、评分很低的插件，在缺失列表里会标出“曾差评”，提醒你当初为什么不要它。

## 换机清单

在“已购账号 → 换机清单”里，可以列出换电脑前要先停用哪些授权、要重新安装哪些插件。清单不含账号、密码和序列号。

# 混音笔记

混音笔记用来记录效果链：每条轨道用了哪些插件、什么顺序、为什么这么用。这里只是记录，不会写入 DAW。

![混音笔记](notes.png)

## 文件夹与笔记

- 左边是笔记树，可以建多层文件夹，比如“混音师 › 鼓组 › Kick”。
- 左下角“新建笔记”“新建文件夹”会建在左边选中的文件夹里。
- 可以把笔记或文件夹拖到另一个文件夹上。
- 重命名：选中后按 F2；删除、“移动到…”在笔记上方。
- 删除文件夹时，默认把里面的笔记和子文件夹移到上一层；勾选“同时删除笔记”会连里面的笔记一起删掉。

## 多选与批量操作

- 点搜索框右边的“多选”，每一行前面出现勾选框，逐行勾选笔记或文件夹；再点一次“多选”退出，同时清空选择。
- 不打开“多选”也可以：按住 Ctrl 点击加选或取消，按住 Shift 点击连续选择，Ctrl + A 全选，Esc 取消选择。
- 选中以后，中间显示选中了哪些，可以一起“移动到…”、加标签、去标签或删除；也可以把选中的一起拖到某个文件夹上。右键选中的条目也有这些操作。
- 选中文件夹时，加标签、去标签对文件夹里的全部笔记生效；移动时整个文件夹一起移；删除时文件夹里的笔记默认移到上一层，勾选“同时删除文件夹里的笔记”才会一起删。
## 编辑一条笔记

- **标签**：人声、贝斯、鼓、吉他、键盘、管弦、合成器、总线、母带等，也可以“添加标签”自定义。
- **描述**：写下这条链的整体思路。
- **输出到**：这条笔记的通道输出到哪里，主输出，或同文件夹里的编组 / 总线。
- **发送、侧链**：记录这条轨道的发送和侧链。
- **效果链**：每一步有一个首选插件，可以加多个备选。每个插件下面写应用思路。
  - 上下箭头调整顺序，× 删除这一步（连同备选）。
  - “备选”按钮展开或收起备选插件，备选里可以“设为首选”。
  - 没安装的插件会标出“未安装”，可以单独“加入心愿单”。

右边是插件搜索区，并按工程使用次数给出建议：

- 点 + 把插件作为新的一步加到末尾。
- 先在中间选中一步，再点 ⇄，可以把插件加为这一步的备选。

“未安装的加入心愿单”会把这条笔记里所有没安装的首选和备选插件一次加入心愿单，已经在心愿单里的会跳过。

## 从工程导入轨道

点“从工程导入轨道…”，选择一个工程，勾选要导入的轨道（可全选、反选）。软件按插槽顺序把轨道上的插件记成笔记。支持 Cubase / Nuendo、Studio One、REAPER、Ableton Live，工程文件只读。

> 目前仅实测过 Cubase。其他 DAW 导入时如果遇到问题，欢迎在 GitHub 的 Issues 页面反馈。

## 路由图

切换到“路由图”，可以看到同一文件夹里的笔记之间的路由：轨道 → 编组 → 效果轨 → 主输出。

- 实线是输出，虚线是发送。
- Ctrl + 鼠标滚轮缩放，按住空白处拖动。

## 分享笔记

笔记的导出、导入在左下角的“导出备份”“导入备份”里：

- **分享给别人**：按文件夹勾选要导出的笔记，可选带上路由。导出文件不包含工程名和路径。
- **导入别人的笔记**：放进单独的“来自 某某 的笔记”文件夹，不会覆盖你自己的笔记。

详见“备份、迁移与分享”一章。

# 闲置报告

闲置报告列出已安装、但长期没进工程的效果器。只统计已经扫描过的工程。

![闲置报告](idle.png)

- **全部 / 从未出现 / 很久没用**：切换查看范围。
- **多久没用算闲置**：自己设定时间。
- **用过的工程**：选中插件查看它最后用在哪些工程。
- 双击查看插件详情。

要不要清理由你决定。按住 Ctrl 或 Shift 可以多选，点“把选中的插件移入垃圾桶…”。这一步只是移入垃圾桶，文件不会被移动或卸载。

# 健康检查

健康检查找出插件安装上的问题。只检查，不会改动文件。

![健康检查](health.png)

| 类别 | 说明 |
| --- | --- |
| 被宿主拉黑 | 宿主启动时扫描这些文件出了问题，所以不再加载。如果同一款还有别的格式，通常不影响使用 |
| 读取失败 | 扫描器读取时失败或超时，可能缺少依赖文件，也可能文件已损坏 |
| 文件缺失 | 以前扫描到过，现在文件不见了。你写的备注和评分还保留着 |
| 只有 32 位 | 只装了 32 位版本。64 位宿主一般不能直接加载 |
| 只有 VST2 | 没有 VST3 版本。以后换用不支持 VST2 的宿主会用不了 |
| 重复安装 | 同一个文件在多个文件夹里各有一份。宿主可能只认其中一份，升级后也容易新旧混用 |
| 版本不一致 | 同一款插件不同文件的版本号不同，可能有格式没有更新到 |
| 留着 32 位副本 | 64 位和 32 位都装了。不用 32 位宿主的话，32 位副本用不上 |
| VST2/VST3 并存 | 只是提示，不算问题。老工程可能还在用 VST2 版，确认工程能打开之前不要删除 |

选中一行可以查看对应的文件。

列表最下面的“按厂家查更新”把已安装的插件按厂家归在一起，方便逐个厂家用浏览器查更新。软件自己不联网。

# 心愿单

心愿单记录想买的插件。

![心愿单](wishes.png)

## 添加心愿

填写插件名，输入厂家时会给出候选，加入时会自动识别厂家和同类插件（判断错了可以手动选）。可以记录：

- **已安装**：电脑上已经扫描到同名插件。
- **到目标价**：现价不高于你定的目标价。
- **曾经不要过**：以前丢进垃圾桶或卸载过的插件，再加入心愿单时会提醒你当时为什么不要它、打了几分。

## 查价与查更新

“查价”“查更新”会用浏览器搜索这款插件。软件自己不联网，不会自动抓取价格，价格需要你手动填写。

买到以后点“标记为已买”，它会移到“已购账号”，在那里填写账号和授权信息。买错了可以在已购账号里“移回心愿单”。

# 已购账号

已购账号记录每款插件用哪个账号购买、怎样授权。

![已购账号](accounts.png)

## 按插件与厂家账号

在插件库里把插件的获取方式标成“已购”，它会自动出现在这里；也可以从心愿单“标记为已买”，或用“批量添加”。

- **按插件**：每款已购插件一行，显示账号、授权、实付和购买日期。
- **厂家账号**：同一个厂家（账号平台）的插件共用一个账号，只需要填一次。个别需要分开的，在插件详情的“登录”里改成“单独账号”。

## 可以记录的信息

| 项目 | 说明 |
| --- | --- |
| 账号、密码 | 默认使用厂家账号；可改为单独账号。填过的账号会记住，账号框右边的下拉可以直接选（只记账号，不记密码） |

## 安全

> 密码和序列号用 Windows DPAPI 加密保存，不会以明文写进数据库。笔记和发票号不加密，请不要把密码写在里面。

用 DPAPI 加密的内容只能在同一个 Windows 账号下解开。如果在另一个账号或另一台电脑上打开数据库，会显示“这个密码是在另一个 Windows 账号下加密的，这里解不开”，原来的内容不会改动。

## 批量操作

- **批量添加**：一次添加多款已购插件。
- **全选 + 保存到选中的插件**：按住 Ctrl 或 Shift 多选，或者先按厂家筛选再点“全选”，可以一次给多款插件填同样的内容。留空的项不会改动。
- **填入 iLok 账号**：把 iLok 那条账号填到所有用 iLok 激活的厂家上。已经填了别的账号的不会覆盖。

## 导出账号

“导出账号”会导出成**明文文件**，用于换电脑或重装系统前迁移。导出的文件请妥善保管，用完删除。日常备份建议用“导出备份”，它可以给密码加密。

# 垃圾桶与卸载

![垃圾桶](trash.png)

## 垃圾桶

不想要的插件移到垃圾桶后，只是在本软件中隐藏，文件不动，DAW 里仍可使用。垃圾桶不会自动清空。

## 卸载插件

在垃圾桶里选中插件（按住 Ctrl 或 Shift 可以多选），点“卸载选中的插件…”。只有点“开始卸载”才会动文件。

- 找到厂家的官方卸载程序时优先用它，操作在官方窗口里完成。
- 软件自己移动的文件只进回收站，不会直接删除。
- 可以为每款插件填写卸载原因，默认带上当初移入垃圾桶的原因，可以修改。
- 完成后会重新扫描，并报告还剩下哪些文件。

## 卸载历史

点垃圾桶上方的“卸载历史”，可以查看所有卸载过的插件：什么时候卸载、怎么卸载（官方卸载程序 / 移到回收站 / Waves 卸载工具 / 在本软件外卸载后扫描发现）、为什么卸载，以及当时的评分和感受。

- 卸载历史和插件记录分开保存，插件记录删了也还在。
- 可以搜索、修改原因、删除单条。
- 又装回来的插件会标出“已装回”。

# Waves 卸载工具（测试中）

> **注意：这个工具还在测试阶段，不保证能完全卸载干净。使用前请自行备份；如出现卸载不干净等问题，作者不承担责任。**

Waves 卸载工具用来卸载全部 Waves 插件，并清理已知位置的残留文件。在“设置”里点“打开工具”。

## 使用步骤

1. **只读检查**：打开后先只读检查，这一步不会改动任何内容。
2. **处理授权**：如果你有官方授权，请先点“打开 Waves Central”，把授权移回云端，然后勾选“我已经处理好授权，或确认不需要处理”。
3. **选择清理范围**：
   - 标准清理 / 完全清理
   - 清理项：勾选表示清理，不勾选表示保留。可以逐项选择保留授权、预设、设置和数据。保留项会先备份，卸载后再放回原位（MSI 卸载时也可能删掉它们）。
   - 标准目录以外的 WaveShell：工具会搜索各磁盘找出来。
4. **选择备份位置**：点“更改”选择，备份会放在 `WhatPlugin_Waves备份` 文件夹里。备份位置不能选在要被清理的地方。
5. **查看预演清单**：先看看具体会删除哪些内容。
6. **开始卸载**：确认无误后点“开始卸载”。

如果需要，可以用“恢复这份备份”把备份放回去。Windows 自带的卸载出问题时，可以点“打开微软修复工具页面”。

> 工具只负责卸载和清理，不会生成、修改或修复任何授权。卸载后恢复的授权文件不保证还能使用。

# DAW 内查询插件 WhatPluginLookup

WhatPluginLookup 是随软件安装的 VST3 小插件。在 DAW 里打开它，就能查看你在 WhatPlugin 里写的插件备注和推荐，不用切换窗口。

- 在 DAW 的插件列表里找到 **WhatPluginLookup**，插到任意轨道上。
- 它只读取数据，音频原样通过，不增加延迟。
- 数据来自 WhatPlugin 主程序，在主程序里更新了内容后，在查询窗口里点“刷新”。

> 如果查询窗口提示“找不到 WhatPlugin”，请先打开一次 WhatPlugin 主程序，再点“刷新”。安装或升级后第一次使用时会遇到这种情况。

查询插件不会出现在你的插件库、健康检查和工程缺失列表里。

# 成就包（可选）

成就包是可选扩展，装上后左侧多出“成就”页面。

- 52 个成就，按收藏、正版、整理、断舍离、工程分析等分组，每个都有图标。
- 隐藏成就在解锁前不显示。

## 安装与卸载

- 安装“with-Achievements”完整安装包，或在已装主程序后安装单独的成就包，版本号要和主程序一致。

## 给自己备份

用来换电脑、重装系统或留底。可以勾选：

| 内容 | 包括 |
| --- | --- |
| 插件评价 | 评分、使用感受、我的标签、混音属性、适合音色 |
| 插件整理 | 功能分类、厂家、标签修正、隐藏、黑名单原因、获取方式 |
| 混音笔记 | 文件夹、标签和路由 |
| 心愿单和已购账号 | 心愿和已购的记录 |

## 导入备份

选好备份文件后，会列出文件里有哪些内容和数量，文件里没有的部分显示为灰色。勾选要导入的部分：

- 勾了的部分：相同条目现有的内容会被覆盖，同名的混音笔记会被备份内容替换。
- 没勾的部分：本机的内容不动。比如只勾“插件评价”，你在本机改过的分类、隐藏和获取方式都保持原样。
- 勾了“账号、密码和序列号”时，下一步要输入备份密码；也可以“跳过账号密码”，其他内容照常导入。
- 工程文件夹和忽略列表只增不减，这台电脑上不存在的文件夹不会添加。

1.3.0 之前导出的备份照常可以导入，当作完整备份。

## 换电脑

1. 在旧电脑上“导出备份”，选“给自己备份”，全部勾选，并设置备份密码。
2. 在“已购账号 → 换机清单”里查看需要先停用的授权。
3. 新电脑安装 WhatPlugin 和你的插件，扫描插件。
4. “导入备份”，输入备份密码。

## 分享给别人

在“导出备份”里选“分享给别人”，可以勾选：

- **插件评价**：下一步挑选要分享的插件，导出评分、使用感受和标签，可选带上使用次数、分类和混音属性。
- **混音笔记**：下一步按文件夹勾选笔记，可选带上路由。不包含工程名和路径。

两样都勾时，依次挑选后存成一个 `.whatplugin-share` 文件；只勾一样时，存成单独的评价文件（`.whatplugin-review`）或笔记文件（`.whatplugin-notes`）。分享的文件都不包含账号和密码。

## 导入别人的分享

用“导入备份”选择别人发来的文件。合在一起的分享文件会先列出里面的评价和笔记，勾选要导入哪些。

- 别人的评价单独保存，不会覆盖你的内容，也不影响推荐。在插件详情里可以“对比”（并排查看自己和别人的评价），也可以“采用”（复制到自己的评分、感受和标签，之后可以继续修改）。
- 别人的笔记放进新的“来自 某某 的笔记”文件夹，不会改动你已有的笔记。
- 你自己导出的评价不需要再导入，会显示为灰色。
- 在“设置 → 别人分享的评价”里可以查看和移除导入的评价。
- 昵称由分享者自己填写，不能证明身份。

# 隐私与安全

- **数据只在本机**：所有数据保存在 `%LOCALAPPDATA%\WhatPlugin\`，软件不上传任何数据。查价、查更新只是打开浏览器搜索，软件本身不联网。
- **工程只读**：工程分析和导入轨道都只读取工程文件，不会修改。
- **不碰授权**：不读取、不修改 iLok / PACE 授权数据。Waves 卸载工具也不会生成、修改或修复授权。
- **扫描安全**：扫描插件不打开插件界面，不改动插件文件。
- **先确认再动文件**：卸载、删除版本、Waves 清理这类会动文件的操作，都会先列出清单，由你确认。
- **加密保存**：密码和序列号用 Windows DPAPI 加密；备份里的密码用备份密码加密。

# 常见问题

**扫描会不会把插件扫坏，或者弹一堆授权窗口？**
不会。扫描在单独的进程里只读插件清单，不创建插件实例，不弹授权窗口。

**有些 VST2 插件被当成了音源（或效果器）？**
WhatPlugin 靠 DAW 自己的插件记录区分 VST2 的效果器和音源。请先在 DAW 里扫描一次新装的插件，再回到 WhatPlugin 扫描新增。仍然不对的，可以在插件详情里手动修改类型。

**某个插件显示“读取失败”？**
可能缺少依赖文件，或文件已经损坏。可以先在 DAW 里确认它能否加载；修复后在“设置”里点“完整重扫”，会重试之前读取失败的插件。

**安装时提示“DeleteFile failed; code 5 拒绝访问”或查询插件被占用？**
宿主软件正在使用查询插件。保存工程、关闭宿主软件后点“重试”；也可以点“忽略”，这次先不更新查询插件。

**DAW 里的查询窗口提示“找不到 WhatPlugin”？**
打开一次 WhatPlugin 主程序，再在查询窗口点“刷新”。

**换了电脑，密码显示解不开？**
密码用 Windows DPAPI 加密，只能在原来的 Windows 账号下解开。换电脑请用“导出备份”（包含账号密码并设置备份密码），在新电脑上导入。

**成就页面没有出现，或提示“和这个版本的主程序不匹配”？**
请安装和主程序版本一致的成就包。

**只想备份评价和混音笔记，不要别的？**
“导出备份”选“给自己备份”，先点“全不选”，再勾“插件评价”和“混音笔记”。导入这份备份时，其他内容都不会动。

**常用清单去哪了？**
1.3.0 去掉了常用清单，它和混音笔记的内容重复。按标签整理常用插件，可以直接在混音笔记里按标签搜索。原来按清单计算的两个成就改为按混音笔记计算。

**卸载软件会删掉我的数据吗？**
不会。数据库保留在 `%LOCALAPPDATA%\WhatPlugin\`，重新安装后还在。

**支持 Mac 吗？**
目前只支持 Windows 10 / 11（64 位）。

**有问题或建议怎么反馈？**
欢迎在 GitHub 项目的 Issues 页面提出，附上软件版本和操作步骤会更快定位：github.com/ChuiFeng-wind/What-Plugin/issues
